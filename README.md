## 💙 About DARI

**DARI**는 다국적·원격 팀의 언어, 문화, 시차 차이로 발생하는 협업 문제를 해결하기 위한 AI 기반 회의 보조 서비스입니다.

AI 리허설부터 실시간 회의 지원, 회의 후 요약까지 글로벌 협업의 전 과정을 지원합니다.

<br>

## ✨ Key Features

| 기능 | 설명 |
|---|---|
| 🤖 **AI Rehearsal** | 문화적 커뮤니케이션 스타일을 반영한 AI 회의 리허설 |
| 💬 **Real-time Translation** | 다국어 회의를 위한 실시간 번역 |
| 🌍 **Timezone Tracker** | 참여자별 시차 및 회의 가능 시간 확인 |
| 📝 **Speaking Cards** | 리허설 결과를 활용한 회의 발언 카드 |
| 📄 **Meeting Summary** | AI 기반 회의 요약 및 후속 업무 정리 |

## 🚀 Getting Started

**1. Clone Repository**

```bash
git clone https://github.com/yuu-nn/DARI.git
cd DARI
```

**2. Install Dependencies**

```bash
npm install
```

**3. Run Development Server**

```bash
npm run dev
```

**4. Build & Lint**

```bash
npm run build
npm run lint
```

**5. Preview**

```bash
npm run preview
```
